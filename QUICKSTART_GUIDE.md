## 🎯 HOW TO RUN

### Fastest Way (Windows):
```bash
QUICKSTART.bat
```

### Manual Setup:
```bash
# Create virtual environment
python -m venv venv

# Activate (Windows)
venv\Scripts\activate

# Activate (Linux/macOS)
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run application
streamlit run app.py
```

### Access the Dashboard:
```
http://localhost:8501
```
