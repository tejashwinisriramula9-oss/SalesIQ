🚀 TO RUN THE APPLICATION:

Option 1 (Fastest - Windows):
   >>> QUICKSTART.bat

Option 2 (Manual):
   >>> python -m venv venv
   >>> venv\Scripts\activate
   >>> pip install -r requirements.txt
   >>> streamlit run app.py

Option 3 (Verify First):
   >>> python verify_setup.py
   >>> streamlit run app.py

Then open: http://localhost:8501
